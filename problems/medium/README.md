# Medium Difficulty Problems

This directory contains LeetCode problems classified as **Medium** difficulty level.

## 📋 Problem List

The following problems are included in `problems-and-solutions.md`:

1. **Two Sum II - Input Array Is Sorted** - Two-pointer optimization
2. **3Sum** - Three-pointer technique with duplicate handling
3. **Container With Most Water** - Greedy two-pointer approach
4. **Longest Substring Without Repeating Characters** - Sliding window technique
5. **Group Anagrams** - Hash map with string sorting/counting
6. **Product of Array Except Self** - Prefix/suffix product technique

## 🎯 Learning Objectives

These problems focus on:
- **Advanced Array Techniques**: Multi-pointer algorithms, prefix/suffix arrays
- **Sliding Window**: Dynamic window size for optimization
- **Hash Map Strategies**: Complex keying and grouping
- **String Algorithms**: Substring processing and anagram detection
- **Optimization Patterns**: Space-time tradeoffs and constraints

## 💡 Difficulty Characteristics

Medium problems typically feature:
- Multi-step solution approaches
- Optimization requirements (time/space)
- Multiple valid solution strategies
- Edge case handling complexity
- Common interview patterns for mid-level positions

Ideal for building strong problem-solving foundations and interview confidence!
