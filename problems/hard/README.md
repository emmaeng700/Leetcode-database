# Hard Difficulty Problems

This directory contains LeetCode problems classified as **Hard** difficulty level.

## 📋 Problem List

The following problems are included in `problems-and-solutions.md`:

1. **Median of Two Sorted Arrays** - Binary search on sorted arrays
2. **Merge k Sorted Lists** - Heap-based optimization and divide-and-conquer
3. **Trapping Rain Water** - Two-pointer with maximum tracking
4. **Sliding Window Maximum** - Deque for efficient range queries
5. **Longest Valid Parentheses** - Stack-based and dynamic programming
6. **Regular Expression Matching** - Dynamic programming with memoization

## 🎯 Learning Objectives

These problems focus on:
- **Advanced Data Structures**: Heaps, deques, and complex state tracking
- **Binary Search**: Complex search space and optimization
- **Dynamic Programming**: Multi-dimensional state and memoization
- **Stack Applications**: Complex parsing and validation
- **Divide and Conquer**: Efficient problem decomposition
- **Pattern Matching**: Regular expressions and string algorithms

## 💡 Difficulty Characteristics

Hard problems typically feature:
- Complex algorithmic techniques
- Multiple solution approaches with different tradeoffs
- Intricate edge case handling
- Advanced time/space complexity analysis
- Real-world system design implications
- Common in senior-level technical interviews
