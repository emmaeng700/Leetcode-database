# Easy Difficulty Problems

This directory contains LeetCode problems classified as **Easy** difficulty level.

## 📋 Problem List

The following problems are included in `problems-and-solutions.md`:

1. **Move Zeroes** - Array manipulation with two-pointer technique
2. **Remove Duplicates from Sorted Array** - In-place array modification
3. **Contains Duplicate** - Hash set for duplicate detection
4. **Maximum Product of Three Numbers** - Sorting and optimization
5. **Subtree of Another Tree** - Tree traversal and pattern matching
6. **Contains Nearby Duplicate** - Sliding window with hash map

## 🎯 Learning Objectives

These problems focus on:
- **Array Manipulation**: Two-pointer techniques, in-place operations
- **Hash Tables**: Efficient lookup and duplicate detection
- **Tree Algorithms**: Basic traversal and comparison
- **String Processing**: Pattern matching and validation
- **Mathematical Operations**: Optimization and edge case handling

## 💡 Difficulty Characteristics

Easy problems typically feature:
- Clear, straightforward problem statements
- Standard algorithm patterns
- Limited edge cases
- Time complexity of O(n) or better
- Space complexity requirements are manageable

Perfect for beginners and interview preparation fundamentals!
